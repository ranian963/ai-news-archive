# 참고 자료 보관 원칙

이 폴더는 카드뉴스에 사용한 자료의 출처를 다시 찾을 수 있도록 관리한다.

- `source-register.json`: 공개 URL, 자료 종류, 사용한 뉴스와 카드 번호를 빌드할 때 갱신한다.
- 카드 본문과 오른쪽 설명은 원문에서 확인한 내용을 편집한 기록이다.
- 현재 공개 저장소에는 제3자 영상 전사나 Threads 본문 전체를 복제하지 않는다. 저작권과 로그인 자료 노출을 피하기 위해 링크만 보관한다.
- 원문 HTML, PDF, 전사 파일, 화면 캡처가 꼭 필요하면 `research/raw/<news-id>/`에 저장한다. 이 경로는 Git에서 제외하며, 별도의 비공개 백업 위치가 필요하다.
- 새 자료를 추가할 때는 원문 URL, 자료 종류, 확인일, 사용 카드 번호를 남긴다. 링크가 사라질 가능성이 큰 자료는 공개 저장소가 아닌 비공개 원본 보관소에 함께 저장한다.

`source-register.json`의 `archiveStatus`가 `link-only`이면 원문 파일은 저장하지 않고 링크와 사용 기록만 보관한다는 뜻이다.
